# Coffret — Cave 71 (Rezé)

Fichiers de prospection pour les coffrets cadeaux d'entreprise.

- `prospection_totale.xlsx` : la grande liste de la campagne d'octobre 2026, triée par département puis ville.
  1018 entreprises. Retirés : les 8 qui ont répondu « STOP » (dont OC Com'unique) et les 43 adresses revenues en erreur.
- `prospection_reze.xlsx` : la petite liste de proximité (à 2 km au plus de la Cave 71), 397 entreprises avec email.
  Vert = nouvelle, orange = dans la liste Rezé, blanc = déjà dans la grande liste. Aucun STOP.
  Onglet « Lisez-moi » : les règles utilisées.

Règle : aucun mail n'est envoyé par Claude ; c'est le client qui envoie.
